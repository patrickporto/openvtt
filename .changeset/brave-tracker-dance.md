Add `@openvtt/canvas-plugin-trackers` — extensible token trackers plugin for `@openvtt/canvas`: inline math editing (`+7`/`-7`/`=-7`), bar/counter kinds, HSV min/max color interpolation, per-audience visibility (gm/owner/others × always/hover/selected/never), side/inset placement, segments approximation, scene defaults with one-click apply, presets, custom value resolvers and `trackers:resolve|label|visibility` bus hooks.
